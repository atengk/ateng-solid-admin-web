## 2. Pinia Setup Store 强类型契约 (`src/stores/`)

所有 Store 均采用 Pinia Setup Store 写法，且脱离组件 `setup()` 调用 `@atengk/vue` Hook 或网络请求时必须显式传入 `adminAuthManager` / `adminTenantManager` / `adminHttpClient`：

| Store 文件                                            | 状态（State / Getters）                                                                                                                                                                                                                                                                                                                                                                                              | 核心动作（Actions）                                                                                                                                                                                                                                                                                                                                                                                                            | 持久化与清理约定                                                                                                                                                                                                                                  |
| :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`useAuthStore`** (`src/stores/auth.ts`)             | 直接代理 `useAuth<AdminProfileVO>({ authManager: adminAuthManager, superAdminRoles: ['super_admin'] })` 的 `token`、`isAuthenticated`、`user`、`roles`、`permissions`（共享底层 `WeakMap` 零漂移）+ `isInitialized: Ref<boolean>` + `tenantEnabled: Ref<boolean>` + `tenantEnabledKnown: Ref<boolean>` | `setTenantEnabled(val)`、`login(dto)`、`fetchUserInfo()`、`logout(opts?: { remote?: boolean; redirect?: string; router?: Router })`、`clearLocalSession(router?)`、`hasPermission(code, mode?)`、`hasRole(role, mode?)`、`syncTokenFromManager()`                                                                                                                                                                              | `token` 由 `adminAuthManager` 持久于 `satoken-admin`；`401` / `101005` 或主动登出均清空认证态、调用 `resetRoutes`、重置租户 `'0'`、清理页签并清空 `DictManager`                                                                                   |
| **`useTenantStore`** (`src/stores/tenant.ts`)         | 桥接 `adminTenantManager`：`ownerTenantId: Ref<string>`、`activeTenantId: ComputedRef<string>`（默认 `'0'`）、`activeTenantName: Ref<string>`、`tenantOptions: Ref<TenantOptionVO[]>`、`switching: Ref<boolean>`、`isSuperAdminTenantSwitchAllowed: ComputedRef<boolean>`、`isObservingTenant: ComputedRef<boolean>`（`tenantEnabled && ownerTenantId === '0' && hasRole('super_admin') && activeTenantId !== '0'`） | `recordLoginTenant(id, name)`、`initForUser(profile)`、`loadTenantOptions()`、`switchTenant(tenantId, router?)`（7 步强时序：`setTenantId` ➔ `DictManager.clearCache()` ➔ 关除 `affix` 外页签 ➔ `resetRoutes` ➔ 重拉 `/auth/info` 与 `/auth/routes` ➔ 路由校准/跳转 `/dashboard` ➔ 更新名称）、`resetToPlatform(router?)`、`setGuardInitializationActive(active)`、`recoverFromInvalidTenant(router?, options?)`、`handleHttpInvalidTenantSwitch(router?)`、`resetLocalTenant()` | `activeTenantId` 持久于 `solid-tenant-id`；普通用户严禁写入非归属 `tenantId`；遇 `100002` 自动复位 `'0'` 而不注销会话                                                                                                                             |

## 3. API 契约目录划分与强类型约定 (`src/api/`)

按后端域 1:1 映射为 **12 个域文件**（可按需置 `src/api/types.ts` 放跨域公共选项类型，分页/响应基类直接复用 `@atengk/core` 的 `PageQuery`/`PageResult`/`Result`）：

- **`src/api/auth/index.ts`**（及 [`types.ts`](../../src/api/auth/types.ts)）：对应 `/admin/auth/**`（含 `captcha`、`login`、`logout`、`info`、`routes`、个人中心 `profile`/`profile/avatar`/`password` 及在线会话 `online/page`/`online/{sessionId}`）
- **`src/api/system/`**（11 个）：`tenant.ts`、`tenant-package.ts`、`user.ts`、`role.ts`、`menu.ts`、`dept.ts`、`post.ts`、`dict.ts`、`config.ts`、`log.ts`、`enum.ts`，对应 `/admin/system/**`

### 强类型与请求编码红线

1. **声明风格**：请求 DTO、查询参数、响应 VO 对象一律使用 `interface`，联合字面量（如 `MenuType = 'M' | 'C' | 'F'`、`GenderValue = '0' | '1' | '2'`、`CommonStatus = 0 | 1`）与工具映射类型使用 `type`；全目录严禁 `any`（不确定载荷用 `unknown`）。
2. **雪花 ID 与字段精度**：所有主键 `id`、父级 `parentId`、`deptId`、`tenantId`、`packageId` 及关联数组 `roleIds`/`menuIds`/`postIds` 100% 声明为 `string` / `string[]`；`sys_user.gender` 声明为 `'0' | '1' | '2'` 与动态字典 `sys_user_gender` 对齐。
3. **长耗时与二进制接口**：
   - `importUsers`（`POST /admin/system/user/import`）必须显式传入请求级超时 **`{ timeout: 120_000 }`**（承接后端 500 行并行 PBKDF2 慢哈希）；
   - 模板下载、数据导出、错误批注回写下载一律复用 `adminHttpClient`（`responseType: 'blob'` 或 `adminHttpClient.download`），严禁裸 `fetch`/`window.open` 绕过认证头与租户头。
